# cpp-student-management-system
Console-based student management system in C++ with grade tracking and performance analysis.

This project was created as part of my university learning process to practice core programming concepts such as:

- Arrays
- Structs
- Functions
- Loops
- Conditionals
- Data management
- Algorithmic thinking

---

## Features

- Add students
- List all students
- Insert student grades
- Search students by student number
- Calculate student averages
- Find the best student in the class
- Calculate class average

---

## Technologies Used

- C++
- Standard Library
- Console Application
